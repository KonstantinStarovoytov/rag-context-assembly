ANSWER
================================================================================
An MCP server exposes tools as executable server primitives that clients can discover and invoke.

The typical flow is:

1. **Declare tool support during server discovery.** Servers advertise their supported capabilities through the `server/discover` request. [2]
2. **List available tools.** The client sends `tools/list` to discover the server’s currently available tools. Listings can be dynamic. [2]
3. **Invoke a tool.** After discovery, the client executes a selected tool with `tools/call`. Tools can perform actions such as file operations, API calls, or database queries. [2]
4. **Receive updates when tools change.** If the available tools are added or modified, the server can send tool-update notifications. Clients must opt in by opening a `subscriptions/listen` stream for the relevant notification types. [1]

MCP uses JSON-RPC 2.0 for these client-server requests and responses. [2] For example, a server might expose `get_alerts` and `get_forecast` as tools. [5]
